# humanslop editor windows
have you ever looked at an editor window/the emote picker and thought it looked like shit ? well this mod somewhat fixes that mayb

so now editor windows have...
- new background texture
- a top bar where the windows are draggable from
- a slightly better close button texture
- customizable window color and opacity
- customizable resize corners
- better looking scaled popups (e.g. editor grid size)
- fancier scroll bar
- resize corner indicators on hover (desktop only)

also *emote picker* now has labels for different categories :3
